# Exercícios de Manipulação de Listas e Strings em Python 🐍

Este repositório contém três scripts básicos em Python focados na entrada de dados pelo usuário, manipulação de strings e armazenamento em listas. É um excelente projeto para iniciantes que desejam entender como tratar e higienizar dados inseridos pelo teclado.

## 📋 Funcionalidades

O projeto é dividido em três exercícios principais:

1. **Cadastro de Nomes (`EXERCICIO 01`):**
   - Recebe 4 nomes via terminal.
   - Remove espaços em branco acidentais antes e depois do texto.
   - Padroniza os nomes para começarem com letra maiúscula (Title Case).
   - Retorna a lista completa de nomes formatados.

2. **Higienização de Telefones (`EXERCICIO 02`):**
   - Recebe 4 números de telefone.
   - Remove formatações indesejadas como `(`, `)`, espaços e `-`.
   - Retorna uma lista de telefones contendo apenas os caracteres limpos.

3. **Validação de Vendedores (`EXERCICIO 03`):**
   - Tenta cadastrar 3 nomes de vendedores.
   - Padroniza as entradas para letras minúsculas.
   - Possui validação: se o usuário enviar um dado vazio (apertar Enter sem digitar nada), o sistema acusa "INFORMAÇÃO INVALIDA!!!" e não adiciona o item em branco à lista.
